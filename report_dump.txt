 313 [Normal              ] 4.2.1 Process Specifications(Algorithms/Pseudocode)
 314 [Normal              ] Algorithm 1: Real-Time Dynamic Heterogeneous Graph Construction
 315 [Normal              ] Algorithm: BuildHeterogeneousDomainGraph
 316 [Normal              ] Input: Feature dictionary F containing {fqdn, ip, ns, registrar, lexical_vector, age, ttl, ssl_valid}
 317 [Normal              ] Output: PyTorch Geometric Data object D = (X, E)
 318 [Normal              ] 1:  Initialize an empty directed graph G using NetworkX: G ← Graph()
 319 [Normal              ] 2:  Define Node IDs:
 320 [Normal              ] 3:      ID_URL ← 0
 321 [Normal              ] 4:      ID_IP  ← 1
 322 [Normal              ] 5:      ID_NS  ← 2
 323 [Normal              ] 6:      ID_REG ← 3
 324 [Normal              ] 7:
 325 [Normal              ] 8:  Construct Feature Vectors:
 326 [Normal              ] 9:      X_url ← Normalize([F.length, F.entropy, F.digit_ratio, F.special_char_count])
 327 [Normal              ] 10:     X_ip  ← Normalize([Hash(F.ip) % 1000, F.ttl, ConvertASN(F.ip)])
 328 [Normal              ] 11:     X_ns  ← Normalize([Hash(F.ns) % 1000, F.ttl])
 329 [Normal              ] 12:     X_reg ← Normalize([F.age, F.ssl_valid, Hash(F.registrar) % 1000])
 330 [Normal              ] 13:
 331 [Normal              ] 14:     Pad vectors X_url, X_ip, X_ns, X_reg with one-hot entity type indicators to uniform dimension d = 16
 332 [Normal              ] 15:
 333 [Normal              ] 16: Add nodes with attributes to G:
 334 [Normal              ] 17:     G.add_node(ID_URL, x=X_url)
 335 [Normal              ] 18:     G.add_node(ID_IP,  x=X_ip)
 336 [Normal              ] 19:     G.add_node(ID_NS,  x=X_ns)
 337 [Normal              ] 20:     G.add_node(ID_REG, x=X_reg)
 338 [Normal              ] 21:
 339 [Normal              ] 22: Add directed relational edges:
 340 [Normal              ] 23:     G.add_edge(ID_URL, ID_IP,  relation="RESOLVES_TO")
 341 [Normal              ] 24:     G.add_edge(ID_URL, ID_NS,  relation="DELEGATED_TO")
 342 [Normal              ] 25:     G.add_edge(ID_URL, ID_REG, relation="REGISTERED_BY")
 343 [Normal              ] 26:
 344 [Normal              ] 27: Add reverse edges to enable bidirectional message propagation:
 345 [Normal              ] 28:     G.add_edge(ID_IP,  ID_URL, relation="RESOLVED_FROM")
 346 [Normal              ] 29:     G.add_edge(ID_NS,  ID_URL, relation="DELEGATES")
 347 [Normal              ] 30:     G.add_edge(ID_REG, ID_URL, relation="REGISTERS")
 348 [Normal              ] 31:
 349 [Normal              ] 32: Add self-loops to maintain self-node states:
 350 [Normal              ] 33:     FOR each node v in [ID_URL, ID_IP, ID_NS, ID_REG] DO
 351 [Normal              ] 34:         G.add_edge(v, v, relation="SELF_LOOP")
 352 [Normal              ] 35:     END FOR
 353 [Normal              ] 36:
 354 [Normal              ] 37: Serialize Graph to PyG Tensors:
 355 [Normal              ] 38:     E ← ExtractEdgeIndexMatrix(G)    // Matrix of shape [2, |E|]
 356 [Normal              ] 39:     X ← StackNodeFeatureTensors(G)    // Matrix of shape [|V|, 16]
 357 [Normal              ] 40:     Construct PyG Data instance: D ← Data(x=X, edge_index=E)
 358 [Normal              ] 41: RETURN D
 359 [Normal              ] Algorithm 2: GCN Forward Propagation and Inference
 360 [Normal              ] Algorithm: GCNForwardInference
 361 [Normal              ] Input: Pre-trained weights {W1, W2, W_fc, B1, B2, B_fc}, Input graph D = (X, E)
 362 [Normal              ] Output: Predicted Class C ∈ {Legitimate, Phishing}, Calibrated Probability P
 363 [Normal              ] 1:  Extract node features X ∈ R^(4 x 16) and edge index E ∈ R^(2 x 10)
 364 [Normal              ] 2:  Compute augmented degree matrix D_hat where D_hat(i, i) = 1 + Sum_j (E(i, j))
 365 [Normal              ] 3:  Compute normalized symmetric adjacency matrix:
 366 [Normal              ] 4:      A_norm = D_hat^(-1/2) * A_hat * D_hat^(-1/2)
 367 [Normal              ] 5:
 368 [Normal              ] 6:  // Layer 1: Graph Convolution & Feature Transformation
 369 [Normal              ] 7:  H1 = A_norm * X * W1
 370 [Normal              ] 8:  H1 = BatchNormalization(H1)
 371 [Normal              ] 9:  H1 = ReLU(H1)
 372 [Normal              ] 10:
 373 [Normal              ] 11: // Layer 2: Relational Aggregation
 374 [Normal              ] 12: H2 = A_norm * H1 * W2
 375 [Normal              ] 13: H2 = BatchNormalization(H2)
 376 [Normal              ] 14: H2 = ReLU(H2)
 377 [Normal              ] 15:
 378 [Normal              ] 16: // Global Readout: Graph-Level Summary Vector
 379 [Normal              ] 17: h_graph = (1 / 4) * Sum_{i=0}^{3} (H2[i, :])   // Global Mean Pooling
 380 [Normal              ] 18:
 381 [Normal              ] 19: // Linear Projection Head & Softmax
 382 [Normal              ] 20: Z = h_graph * W_fc + B_fc                       // Logits in R^2
 383 [Normal              ] 21: Probabilities = Softmax(Z)                      // [P(Legitimate), P(Phishing)]
 384 [Normal              ] 22:
 385 [Normal              ] 23: IF Probabilities[1] >= 0.50 THEN
 386 [Normal              ] 24:     C ← "Phishing"
 387 [Normal              ] 25:     P ← Probabilities[1]
 388 [Normal              ] 26: ELSE
 389 [Normal              ] 27:     C ← "Legitimate"
 390 [Normal              ] 28:     P ← Probabilities[0]
 391 [Normal              ] 29: END IF
 392 [Normal              ] 30: RETURN (C, P)
