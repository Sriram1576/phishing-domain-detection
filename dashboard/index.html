About PhishNet-GNN

Graph Neural Network architecture designed for real-time proactive phishing infrastructure detection.

The Challenge: Why Blacklists Fail

Traditional phishing countermeasures rely on static blacklists and rule heuristics. These fail against zero-day campaigns, domain generation algorithms (DGAs), and fast-flux networks where domains exist for only minutes before rotating.

The Relational Insight: Phishing campaigns do not operate in isolation. Attackers reuse infrastructure — sharing IP subnets, bulletproof nameservers, autonomous systems, and lexical token templates.

PhishNet-GNN models domains as nodes within a heterogeneous infrastructure graph. By propagating embeddings through multi-relational graph convolutions, the model detects suspicious clusters based on infrastructure topology.

Safety Disclaimer & Protocol

Academic Security Tool Disclaimer:

This software is an academic security-analysis tool developed for research and threat detection. A prediction represents a calculated statistical risk indicator, not legal proof of malicious activity.
